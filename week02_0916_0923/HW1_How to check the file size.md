# Fantastic Genomic Biomarkers and Where to Find Them Practical Course (Part II)


## HW1: How to check the file size of fastq.gz file?


1. Log into NCHC using Terminal/cmd.
2. Go to the folder where the fastq.gz files are located.
   ```
   cd /work/{supercomputer_account}/result/fastqc/
   ```   
3. Enter ``ls -lh``, the file size will be displayed in the red box shown in the image.
   ```
   ls -lh
   ```  
   ![image](https://hackmd.io/_uploads/By7g0-bczl.png)
